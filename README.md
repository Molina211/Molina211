## Featured Project

### Web Management System for a Car Wash

Stack: Angular, Spring Boot, MySQL, Docker and Jenkins.

Highlights:

- Full system design and implementation from architecture to deployment.
- Secure authentication with password encryption and unique email validation.
- Role-based access for Client, Employee, and Administrator.
- Booking system with real-time availability checks and double-booking prevention.
- Dynamic discounts based on vehicle type.
- Extended CRUD with optimized filters and searches.
- Endpoint protection by role.
- Layered structure with Controller, Service, and Repository.
- Docker-based containerization for structured deployment.
- Basic automation with Jenkins.
